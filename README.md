# ShardBorne
Um jogo de ação 2D em perspetiva lateral onde acompanhamos a jornada do protagonista **Tharion**. 


## 🎮 Características Principais
* **Ação Side-scroller:** Movimentação e combate em 2D.
* **Interface e UI:** Sistemas completos de navegação, incluindo menus de pausa dinâmicos.
* **Integração de Áudio:** Efeitos sonoros imersivos e banda sonora integrada.
* **Narrativa Visual:** Universo expandido com materiais promocionais em formato *motion comic*.

## 🛠️ Tecnologias e Ferramentas
* **Motor de Jogo:** Unity
* **Programação:** C#
* **Edição de Áudio:** Audacity
